{%- comment -%} The version menus: one for the dashboard's docs (latest at the root, develop under /develop/) and one for the widgets (latest under /widgets/, develop under /widgets/develop/). The two parts are built and released apart (scripts/pages.sh, DOCS_PART). Nothing here depends on the version a page is built for: it is read from the address, the latest versions from /version.json, which the site's build writes. So a release is a copy of develop's site (scripts/pages-promote.sh). A menu of this part opens the same page in the other version, or its home page when that page is not there; the other part's menu opens that part's home page. On develop a banner says what is being read. On a narrow screen, where the theme folds this header into its menu, the menus move next to the menu button. {%- endcomment -%} {%- if site.docs_channel -%}
